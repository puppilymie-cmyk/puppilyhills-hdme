# LINE限定 お試着ルーム (/fitting-room)

## 目的

Instagramで発表した新作のお洋服を、LINEにご登録いただいたご家族だけが、ご自宅で「この子の写真」に重ねてお試着できるようにする。
気に入った一着は、そのままLINEでサイズ相談・お取り置き・ご購入につなげる。
販売のためだけでなく、お試着の一枚そのものが「記憶と記録」になる体験として設計している。

## 動線

1. Instagramで新作を投稿し、プロフィールリンクやストーリーズから `/fitting-room` へ案内する。
2. 「LINEでログインして入る」からLINEログイン。ログイン画面で公式アカウントの友だち追加もあわせて案内される。
3. サーバーがLINEに友だち状態を問い合わせ、友だちであればお試着ルームが開く(7日間有効のCookie)。友だちでなければ、友だち追加ボタンと再ログインを案内する。
4. この子の写真を選び、お洋服を重ねて位置・大きさ・傾きを調整、画像として保存できる。
5. 「この一着をLINEで相談・お取り置き」から、商品名入りのメッセージ下書きが入った状態でLINEが開く。

## 新作を追加する手順

1. お洋服だけを切り抜いた背景透過PNGを用意し、`public/images/fitting/` に置く(試着用)。
2. 商品写真(Instagramと同じ写真で可)も同じフォルダに置く。
3. `content/fitting-room.ts` の `fittingItems` に1件追加する。
   - `price` と `limitedQuantity` は確定値のみ。未確定なら `null`(画面には出ない)。
   - `instagramUrl` には紹介投稿のURLを入れる。
4. 表示確認用の `sample: true` の項目は、実際の新作を入れたら削除する。

## LINEログインの設定(初回のみ)

1. LINE Developers で、Puppily HillsのLINE公式アカウントと同じプロバイダーに「LINEログイン」チャネルを作成する。
2. チャネルの「LINEログイン設定」でコールバックURLに `https://(本番ドメイン)/fitting-room/callback` を登録する。
3. チャネル基本設定の「リンクされたLINE公式アカウント」にPuppily Hillsの公式アカウントを設定する(これがないと友だち確認ができない)。
4. チャネルを「公開」にする(開発中のままだと、チャネルに登録されたテスターしかログインできない)。
5. ホスティング先の環境変数に `LINE_LOGIN_CHANNEL_ID`・`LINE_LOGIN_CHANNEL_SECRET`・`FITTING_ROOM_SECRET` を設定する(`.env.example` 参照)。リポジトリには絶対に書かない。

いずれかが未設定の間は「準備中」と表示され、誰も入室できない。

## 入室の仕組みと限界

- ログインで使うのは「友だちかどうか」の確認だけ。LINEのお名前・プロフィール画像・ユーザーIDは保存しない。
- 入室Cookieは7日間有効。その間に友だち解除された方も、期限まではそのまま入れる。
- `FITTING_ROOM_SECRET` を変更すると、全員の入室が解除される(新作の切り替え時などに使える)。
- LINEアプリ内のブラウザから開くと、ほぼワンタップでログインできる。Instagramのアプリ内ブラウザでは、メールアドレスやQRコードでのログインが必要になることがある。
- 実装は LINE Login v2.1(認可コード方式)と友だち状態取得API(`/friendship/v1/status`)。LINEの仕様変更時は `lib/line-login.ts` を確認する。

## 守ること

- 「数量限定」は実際に数が限られている場合のみ。数を推測で書かない、煽らない。
- 画面上の試着はイメージであり、着心地・サイズはご来店時にスタッフが実際に着せて確かめる(体に負担がないかを最優先)。
- お客様の写真は端末内で処理され、サーバーには送信・保存しない。この仕組みを変える場合は、同意とプライバシー表記を見直す。
- Instagramの写真を自動で取得する仕組みではない。使用する画像はオーナーが提供・承認したものだけ。

## 公開前の確認事項

- LINE公式アカウントID (`content/fitting-room.ts` の `lineAccountId`) が実際のIDと一致しているか。
- LINEログインチャネルの設定(コールバックURL・リンクされた公式アカウント・公開状態)が済んでいるか。
- 実際のスマホで、友だち登録済み/未登録の両方のアカウントでログインを試したか。
- 実際の新作データ・画像に差し替えたか。
