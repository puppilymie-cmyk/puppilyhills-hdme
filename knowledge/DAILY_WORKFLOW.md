# Daily Content Workflow

## Current operating mode

Use assisted production, not unattended publication.

1. Select one content pillar and one audience need.
2. Check the approved content calendar and asset library.
3. Draft one script in Mie's brand voice.
4. Identify every factual and medical claim.
5. Verify current operational facts.
6. Obtain veterinary review where required.
7. Generate or edit media only from approved source assets.
8. If using an avatar, create a clearly traceable draft.
9. Present the complete post package for owner approval:
   - spoken script;
   - on-screen text;
   - caption;
   - thumbnail text;
   - asset sources;
   - factual sources;
   - risk/approval status;
   - proposed date and time.
10. Publish only after explicit approval.
11. Record the final URL, date, asset version, and approval.

## Daily output format

### Purpose
One sentence.

### Audience
One specific audience and concern.

### Script
Natural spoken Japanese, normally under 60 seconds unless otherwise requested.

### Caption
Readable Instagram copy with a single central message.

### Visual plan
Shot-by-shot or asset list.

### Verification
Facts checked, sources, and outstanding questions.

### Approval
LOW RISK / REVIEW / VETERINARY REVIEW / OWNER FINAL APPROVAL.

### Status
DRAFT / READY FOR REVIEW / APPROVED / SCHEDULED / PUBLISHED.

## Automation boundary

Automate drafting, organization, reminders, rendering, and scheduling preparation first. Do not enable fully automatic public posting until:

- Instagram's approved API connection is configured;
- asset rights and avatar consent are documented;
- account security is reviewed;
- error handling and a kill switch exist;
- owner and veterinary approval rules are technically enforced;
- a supervised trial period succeeds.

Claude Code alone is not an avatar generator or an Instagram publishing account. External authorized services and APIs are required.
